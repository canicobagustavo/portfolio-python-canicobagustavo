# EP3 — gestão de estoque

## Objetivo
Exercício de programação para ler dados de lojas, clientes, produtos, estoque e operações; atualizar o inventário e o caixa; e produzir relatórios.

## Dados necessários
Coloque estes arquivos CSV na mesma pasta do notebook:
- `inventario.csv`
- `operacoes.csv`
- `clientes.csv`
- `lojas.csv`
- `produtos.csv`

Os CSVs não estavam no arquivo recebido, então a execução completa não pôde ser validada. O notebook não contém dados inventados para substituir os originais.

## Alteração feita
Foi mantida a implementação mais recente das células do notebook original, removidas versões intermediárias duplicadas e corrigida a condição `if __name__ == "__main__"` para que o ponto de entrada seja reconhecido ao executar o arquivo como script.
