# Física experimental

Os notebooks analisam experimentos de difração, polarização e lei de Brewster.

- Difração: dados incluídos no código.
- Polarização: dados incluídos no código.
- Lei de Brewster: requer a planilha externa `ANGLE-VOLTS.xlsx`, não incluída neste pacote.

Os resultados são mantidos como trabalhos experimentais/acadêmicos; revise as unidades, os parâmetros de ajuste e as conclusões físicas antes de reutilizar os números em um relatório.
