# Como publicar este repositório no GitHub

1. Descompacte `portfolio_github_pronto.zip` em uma pasta.
2. Entre no GitHub e crie um repositório novo, por exemplo `portfolio-python`.
3. Selecione a opção de criar o repositório vazio; não precisa gerar outro README, pois este pacote já contém um.
4. Envie os arquivos e pastas desta pasta para o repositório. Você também pode usar Git no terminal.
5. Antes de tornar o repositório público, confira os dados e as observações de cada projeto.

## Comandos opcionais (Git instalado)

Dentro da pasta descompactada:

```bash
git init
git add .
git commit -m "Organiza projetos acadêmicos para portfólio"
git branch -M main
git remote add origin URL_DO_SEU_REPOSITORIO
git push -u origin main
```

Substitua `URL_DO_SEU_REPOSITORIO` pela URL real do repositório criado no GitHub. Não publique tokens, senhas nem dados que você não tenha autorização para compartilhar.
